# Login Page Design

## Project Description

This project features a modern and responsive login page designed using HTML and CSS. The page includes a user-friendly interface with icons, a login form, and additional elements such as "Forgot Password" and social media login options. The design aims to provide a visually appealing and functional login experience.

## Technologies Used

- HTML
- CSS
- Font Awesome (for icons)

## Setup and Run Instructions

### Prerequisites

- A web browser (e.g., Google Chrome, Firefox, Safari).

### Setup Instructions

1. **Clone the Project Repository:**
   - Open your terminal or command prompt.
   - Run the following command to clone the repository:
     ```bash
     git clone https://github.com/yourusername/login-page.git
     ```
   - Replace `yourusername` with your GitHub username and `login-page` with the name of your repository.

2. **Navigate to the Project Directory:**
   - Change directory to your project folder:
     ```bash
     cd login-page
     ```

3. **Open the Project:**
   - Open the `index.html` file in your preferred web browser to view the login page.

## Key Features and Functionalities Implemented

1. **Login Form:**
   - Username and password fields with associated icons.
   - "Remember Me" checkbox and "Forgot Password?" link.


2. **Styling and Layout:**
   - Responsive design using CSS Flexbox.
   - Modern look with a gradient background, rounded corners, and box shadow.


3. **Social Media Login Options:**
   - Icons for Facebook, Twitter, and Instagram.
   - Links to social media platforms.


4. **Button Styles:**
   - Custom styles for the sign-in button, including hover effects.


5. **Additional Features:**
   - Hover effects for icons and interactive elements.
   - Responsive design ensuring compatibility with various screen sizes.


## CSS Styles Overview

The `main.css` file includes styles for:

- **General Layout**: Flexbox for centering content and responsive design.
- **Form Elements**: Styling for input fields, icons, and buttons.
- **Interactive Elements**: Hover effects for buttons and links.
